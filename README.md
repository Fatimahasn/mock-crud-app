# React JSONPlaceholder CRUD App

A React frontend application demonstrating **CRUD operations** (Create, Read, Update, Delete) and **pagination** using the [JSONPlaceholder](https://jsonplaceholder.typicode.com) fake APIs.

Since JSONPlaceholder provides mock APIs, all add, update, and delete actions appear to work but **data resets on page reload** (because changes are not persisted on the server).

---

## 🚀 Features
- View posts with pagination
- Add new posts
- Edit existing posts
- Delete posts
- Add comments to posts
- Form validation for input fields
- State management with **Redux**

---

## 🛠️ Tech Stack
- **React** (frontend framework)
- **Redux** (state management)
- **React Router** (navigation)
- **JSONPlaceholder API** (mock backend)
